5 · EXPORT

« Enregistrer dans ce navigateur » met le perso dans le jeu en direct s'il est ouvert depuis le même navigateur et le même site/dossier (aucun rechargement nécessaire). Pour que tous les joueurs le voient, utilise le catalogue public ci-dessous.

6 · PERSONNAGES ENREGISTRÉS

Télécharge zkr3d-chars.json (tous les persos enregistrés ci-dessus). Mets ce fichier dans le même dossier que zkr3d.html sur ton site (ex. GitHub Pages) : le jeu le charge au démarrage et chaque joueur voit les persos. Pour retirer un perso du public, supprime-le de la liste puis ré-exporte le catalogue.

7 · PUBLICATION POUR TOUS LES JOUEURS

Envoie automatiquement le catalogue sur ton dépôt GitHub (celui de ton site GitHub Pages) : chaque joueur reçoit les persos au prochain chargement du jeu.
Token : GitHub → Settings → Developer settings → Fine-grained tokens → limité à ce dépôt, permission « Contents : Read and write ». Le chemin doit être dans le même dossier que zkr3d.html (ex. jeu/zkr3d-chars.json si le jeu est dans /jeu).
